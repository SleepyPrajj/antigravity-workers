# Security

Use the latest version on `main`. This local MCP server can start workers, read explicitly supplied files, and apply reviewed patches. It is not a multi-user service or a substitute for OS and provider permissions.

Keep credentials, account files, runtime state, logs, worktrees, and private media outside the repository. Do not expose the local runtime transport to untrusted users. Treat worker responses and generated artifacts as untrusted until reviewed.

To report a vulnerability, use GitHub's private vulnerability reporting option if available on this repository. If it is unavailable, open an issue requesting a private contact channel without including exploit details, secrets, or affected private data. Share sensitive details only after the maintainer supplies a private channel.
